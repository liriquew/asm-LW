## Репозиторий содержит лабораторную работу по Операционным Системам

Суть лабы заключается в создании библиотеки на ассемблере. 

В репозитории имеется как и исходный код библиотеки `LW5/algorithm.asm`, так и скрипт для ее сборки `LW5/compile.bat`. Также есть 2 проекта, один линкует библиотеку статически (`StaticLink`), другой подгружает динамически (`DynamicLink`).

В библиотеке есть одна единственная экспортируемая функция, которая удаляет из строки четные слова (краевые случаи учтены).

Для сборки необходим masm32 c [ссылка](https://www.masm32.com/).
